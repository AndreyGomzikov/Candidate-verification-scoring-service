# Ответы на обращения через существующий Telegram-канал модерации

## Назначение

**Новая функция:** кнопка **«✉️ Ответить»** появляется в карточке обращения кандидата,
опубликованной в `ADMIN_CHAT_ID` (включая обычный Telegram-канал). Дополнительная
группа/супергруппа не требуется. При этом канал продолжает принимать анкеты,
кнопки одобрения и отклонения, уведомления об ошибках и кнопки закрытия обращения.

### Как отвечает модератор

1. Кандидат, завершивший анкету, отправляет текст в личный чат бота.
2. В канале модерации появляется **📩 Обращение #N** с кнопками
   **«✉️ Ответить»** и **«✅ Закрыть обращение»**.
3. Модератор нажимает **«✉️ Ответить»**, открывается личный чат с *тем самым*
   ботом Gatekeeper. При первом обращении необходимо нажать **Start**.
4. Бот сверяет **реальный Telegram ID пользователя** с `ADMIN_USER_IDS`, либо
   (когда список пуст) проверяет административный статус в `ADMIN_CHAT_ID`.
5. Бот присылает сообщение **«✉️ Ответ на обращение #N»** с режимом принудительного
   ответа (`ForceReply`). Модератор вводит текст **как ответ на это сообщение**.
   Если режим ответа закрыли, используйте «Ответить» на сообщение-приглашение.
6. Ответ записывается в существующую надёжную очередь `support_messages` и
   доставляется кандидату **от имени бота**, без раскрытия имени администратора.
7. Если доставка Telegram временно недоступна, бот сообщает, что ответ сохранён,
   и повторяет отправку автоматически. Не нужно дублировать текст.
8. В канале модерации по окончании беседы нажмите **«✅ Закрыть обращение»**.
   Новое сообщение кандидата создаёт новое обращение.

### Конфигурация

Новых переменных `.env` нет. Используются текущие `BOT_TOKEN`, `ADMIN_CHAT_ID`,
`TARGET_CHAT_ID`, `ADMIN_USER_IDS`. Кнопка формирует ссылку на **действительно
запущенного бота** по username из Telegram API; при смене `BOT_TOKEN` и
пересоздании контейнера ссылки новых обращений будут указывать на нового бота.

Нужно добавить бота администратором канала модерации с правом **Post Messages**.
Для проверки прав модераторов, если `ADMIN_USER_IDS` пуст, бот должен иметь доступ
к информации о членстве в канале. Личные сообщения Telegram бот может отправлять
модератору только после того, как тот открыл/запустил бота — глубокая ссылка
упрощает это действие.

### Безопасность и надёжность

- Прямая ссылка содержит только номер обращения, **не** является правом доступа.
- Авторизация модератора проверяется при каждом начале и отправке ответа.
- Простое сообщение с номером обращения не отправит ничего кандидату: требуется
  ответ на настоящее **сообщение бота** с маркером обращения.
- Нельзя отвечать на закрытые и несуществующие обращения.
- Повторное получение одного и того же Telegram-сообщения не создаёт дубликатов.
- Два администратора могут использовать одинаковые `message_id`, поскольку
  сообщения из их приватных чатов идентифицируются по паре `(chat_id, message_id)`.
- После перезапуска контейнера контекст ответа не пропадёт: номер обращения
  сохраняется в сообщении-приглашении Telegram, а история — в PostgreSQL.
- Спам-фильтры, оценка кандидатов и трёхэтапный Decision Gate **не изменяются**.
- Старый путь ответа через «Ответить» в супергруппе остаётся поддерживаемым.

### Внедрение

1. Сделать резервную копию PostgreSQL по существующей инструкции развёртывания.
2. Запустить `python -m pytest -q` в CI/GitHub Actions; прежде чем менять рабочий
   сервер, убедиться, что тесты прошли в среде с `aiosqlite`.
3. Развернуть собранный релиз стандартным способом, сохранив текущий `.env`.
4. Не выполнять `docker compose down -v` и не удалять PostgreSQL volume.
5. Открыть личный чат ботa от имени модератора (если ещё не открыт).
6. С тестового аккаунта, прошедшего анкету, написать боту произвольный вопрос.
7. В канале проверить обе кнопки и открыть «✉️ Ответить».
8. В ЛС модератора ответить на сообщение **«✉️ Ответ на обращение #N»**.
9. Проверить доставку от имени бота, отсутствие имени администратора в тексте,
   корректный статус заявки и работу «✅ Закрыть обращение».

> Карточки обращений, отправленные до обновления, не получат кнопку задним
> числом. Их можно закрыть; при новом обращении кандидата будет отправлена
> карточка с новой кнопкой. При необходимости администратор может открыть
> `https://t.me/<username_бота>?start=sreply_<номер_обращения>` вручную,
> если обращение ещё открыто.
